## Compiling

From main directory (where _build.sh_ and _build.bat_ are):

Unix-like:

> ./build.sh

Windows: Dbl-Click over _build.bat_ or in command line:

> build

Executable program will be created in _bin/<Target>/_ directory.

On Windows, the program expects that system and compilation matching _SDL3.dll_
and other libraries in the same folder (it's unusual have this library in a 
common shared or system folder). In Windows, excutable folder is autoopened.
